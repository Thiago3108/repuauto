# Cómo contribuir

Todo lo que necesitas para trabajar en RepuAuto está en estas guías. Léelas en este orden:

1. [Guía de inicio](GUIA-INICIO.md): instalar Python y PostgreSQL 18, crear las bases de datos y el `.env`, y arrancar la app.
2. [Plan de trabajo](PLAN-DE-TRABAJO.md): qué te toca, a quién esperas, el orden de las migraciones, las convenciones y la definición de terminado.
3. [Guía de git](GUIA-GIT.md): ramas `feature/US-XX-...`, commits `US-XX TY: ...`, pull requests con Squash and merge, revisión y conflictos de migraciones.
4. [Guía de Trello](docs/guias/TRELLO.md): cómo mover tu tarjeta en cada paso.

**En resumen:** nadie sube cambios directo a `main`. Cada tarea va en su rama, entra por un pull request con el CI en verde y aprobado por otro integrante, y se une con **Squash and merge**.
